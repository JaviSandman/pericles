# Herramienta Pericles

Análisis electoral interactivo de España (1977–2024). Streamlit + datos oficiales del Ministerio del Interior.

## Instalación

**Requisitos**: Windows 10/11 · Python 3.10 o superior ([descargar](https://www.python.org/downloads/))

1. Descarga el archivo **`pericles-vX.Y.Z.zip`** desde la sección [Releases](../../releases).
2. Extrae la carpeta en cualquier lugar de tu disco duro.
3. Doble clic en **`instalar.bat`** — descarga las dependencias y prepara la aplicación. Solo hay que hacerlo una vez.
4. Doble clic en **`pericles.bat`** para abrir la aplicación en el navegador.

## Uso diario

Doble clic en **`pericles.bat`** — abre la app en el navegador automáticamente.

## Contenido

| Módulo | Descripción |
|---|---|
| Presentación | Portada con índice de las 13 secciones |
| Participación | Evolución histórica por tipo, CCAA, provincia y municipio |
| Congreso | Resultados 1977–2023: escaños, votos, mapas |
| Senado | Resultados 1977–2023: senadores, votos |
| Municipales | Resultados 1979–2023: alcaldías y concejales |
| Europeas | Resultados 1987–2024: eurodiputados |
| Mayorías | Análisis de mayorías por convocatoria |
| Comparador | Comparación entre circunscripciones |
| Candidaturas | Resultados por partido (Congreso, Senado, Europeas, Municipales) |

## Datos

Fuente: [Ministerio del Interior — Resultados Electorales](https://www.infoelectoral.mir.es/).  
Todos los datos son de acceso público.
